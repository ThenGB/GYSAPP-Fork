# Project Instructions

This project uses the **Superpowers** methodology for AI agents.

## Superpowers Skills
The skills for this repository are available in `.devin/skills` and `.github/skills`. 
When working on this project, ALWAYS follow the guidelines in `.devin/skills/using-superpowers/SKILL.md`. Check for relevant skills before executing tasks.

## MCP Servers
The **Marionette MCP Server** (Flutter MCP) is configured for testing the Flutter application. It allows interaction with the running Flutter app via the VM Service URI. 

Use the Marionette MCP capabilities (via `mcp_config.json`) when you need to run UI tests, take screenshots, or interact with the Flutter widget tree.
